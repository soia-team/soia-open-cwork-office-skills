# 视觉机制：中国传统构图 20 式与 350 版式分类索引（Chinese Traditional Composition & 350 Layout Taxonomy）

本文件不是独立 preset，而是可叠加在 `editorial_research_minimal`、`archival_print`、`poster_type_stage`、`presentation_grid` 等家族上的 `visual_mechanism=chinese_traditional_composition` 词条。它吸收了开源项目 `350-layout-compositions` 的 8 大一级分类（`01 构图逻辑 86` / `02 视觉原则 45` / `03 出版广告 36` / `04 字体网格 54` / `05 网页 UI 79` / `06 影视画面 14` / `07 中国传统构图 20` / `08 演示文稿 16`），重点将 **20 种中国传统构图（`315–334`）** 编译为可直接驱动生图的构图参数与验收准则。

## 一、三远、透视与游观（`315–320`）

| 编号与名称 | 空间经营核心 | 推荐画幅与场景 | Prompt 构图指令要点 |
|---|---|---|---|
| `315 高远法` | 自山下而仰山巅，山势壁立突兀、气势崇高 | `3:4` / `4:5` 竖版海报、哲思封面 | 低机位仰视，主峰纵向贯通画面 60%–75%，顶部或侧翼留白题字 |
| `316 深远法` | 自山前而窥山后，重峦叠嶂、云雾掩映 | `3:2` / `16:9` 深度长文配图 | 前景苍松危石（浓墨）、中景云谷山径（淡墨）、远景层峦（清墨），建立至少 3 层景深 |
| `317 平远法` | 自近山而望远山，冲融平旷、静水阔远 | **`2.35:1` 公众号首图首选**、`16:9` 横幅 | 低地平线（下 1/3 处），近景坡岸石径缓缓延伸，远山低缓缥缈，中上大面积宣纸留白落主标题 |
| `318 三远综合` | 兼备高耸主峰、深谷幽径与平旷远水 | `16:9` / `3:2` 史诗或综述封面 | 主峰偏居一侧，中景深谷迂回，另一侧平远开合 |
| `319 散点透视` | 突破单一灭点，多视点并置同一长卷 | `2.35:1` / `16:9` 流程/叙事长图 | 按阅读顺序（左→右或上→下）布置 2–3 个叙事节点，云水或山径自然串联 |
| `320 游观式构图` | 可行、可望、可游、可居的移步换景 | `3:2` / `4:5` 读书与人文随笔 | 蜿蜒山径、石桥、半山茅亭引导视线穿行，人物极小（点景） |

## 二、取景与景式（`321–325`）

| 编号与名称 | 空间经营核心 | 推荐画幅与场景 | Prompt 构图指令要点 |
|---|---|---|---|
| `321 全景式构图` | 大山堂堂，主峰居中统摄群山（北宋范宽式） | `3:4` / `1:1` 庄重主题封面 | 主体居中稳固，下部近景林木拱卫，适合厚重历史或体系总纲 |
| `322 一河两岸式` | 近岸实景—中景辽阔水面/孤舟—远岸淡墨山影（倪瓒式） | **`16:9` / `3:2` 正文意境配图首选** | 上下三段式：下岸坡石或扁舟，中段大面积静水留白，上段远山淡淡横抹，标题居上或居中 |
| `323 边角式构图` | 「马一角、夏半边」，实景浓缩于一角或半边 | **`2.35:1` 公众号封面 / `1:1` 分享卡** | 山石古松收拢于左下/右下角（占画幅 25%–35%），正中与上方留出完整宣纸呼吸区承载大字书法 |
| `324 截景式构图` | 截取山腰、案头或庭院局部特写 | `3:2` / `4:5` 器物与书斋随笔 | 聚焦窗畔竹影、案头古籍茶盏、半截怪石，以小见大 |
| `325 折枝式构图` | 孤松、寒梅或竹枝从画框边缘斜探入画 | `2.35:1` / `16:9` 极简留白配图 | 枝干自右侧或左上边缘破框斜出，姿态苍劲，不画全株，与中轴标题形成呼应 |

## 三、留白、虚实与章法（`326–334`）

- **`326 留白构图` & `327 计白当黑`**：空白处并非“没画完”，而是云雾、江水、天光与气息流转之地；留白占比控制在 **35%–60%**（有字图预留中央或上方净区，禁止留白 >70% 导致画面空旷）。
- **`328 虚实相生` & `329 疏密相间`**：「密不透风，疏可跑马」——笔墨密集处（松针、皴擦、印章）与极简留白处形成强烈节奏对比。
- **`330 主宾关系` & `331 开合构图` & `332 起承转合`**：主景（高山/孤舟/大字标题）明确统摄宾景（远山/飞鸟/小印）；画面有起势、承接、转折与收束（常以一枚朱文小印或远帆收口）。
- **`333 藏露关系` & `334 欹正关系`**：亭台半隐于松云（藏露），奇石斜松虽险而重心稳固（欹正）。

## 四、编译字段与验收（Level B 契约）

- `compile_fields`：
  - `composition_schema`：从 `315–334` 中点名 1–2 个主章法（如 `平远法 + 边角式` 或 `一河两岸式 + 计白当黑`）。
  - `three_layer_depth`：明确前景（实/浓墨）、中景（渡/舟/径）、远景（虚/淡墨远山）的空间层次。
  - `whitespace_and_title_zone`：明确留白比例（35%–60%）及文字安全区（微信 `2.35:1` 封面必须保证文字与核心意象落在中央 `1:1` 正方形安全区内）。
  - `seal_and_calligraphy_anchor`：大字书法与朱文闲章的平衡位置（闲章不抢主标题，不伪造未授权私印）。
- `acceptance`：
  - `composition_matches_schema`：画面空间关系与所选传统构图章法一致，拒绝西式中心对称剪贴画感。
  - `title_in_safe_blank_zone`：文字位于留白净区，不与浓墨山石/人物面部重叠，缩略图清晰可读。
  - `breathing_room_balanced`：虚实有度，既不拥挤成黑块，也不因字号过小显得空旷。
