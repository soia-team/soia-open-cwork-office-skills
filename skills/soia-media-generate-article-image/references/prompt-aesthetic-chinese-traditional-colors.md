# 美学系统：中华传统色与宣纸水墨系统（Chinese Traditional Colors & Xuan Paper System）

本文件定义 `aesthetic_system=chinese_traditional_colors`，吸收开源项目 `zhongguo-traditional-colors`（742 种中华传统色与 8,904 组配色）的色彩角色体系，专为人文随笔、读书笔记、东方哲思、国风知识卡及公众号「半山观心」等系列提供零试错的传统色盘与材质规范。

## 一、核心色彩角色（Color Roles）

生成 Prompt 时必须按**角色（Role）**指定传统色名与 HEX 参考值，禁止只写笼统的“中国风颜色”：

### 1. 纸本与留白底色（`paper_base_color`）
拒绝刺眼纯白（`#FFFFFF`）或脏污暗黄，采用温润、透气的手工纸本色：
- **宣纸白** `#F7F2E7` / **鱼肚白** `#F8F4ED`：清雅透亮，适合大多数公众号封面与正文图。
- **古籍米** `#EFE7D6` / **素色** `#E4DFD3`：微带岁月温润感，适合书斋、历史、心性修养主题。
- **月白** `#D6ECF0` / **天水碧** `#C6DFDF`：清冷空灵，适合江雪、夜航、独处冥想主题。

### 2. 墨分五色与山石结构色（`ink_and_mineral_structure`）
遵循传统水墨「焦、浓、重、淡、清」五阶层次，暗部使用深冷色或纯正松烟墨，不用浑浊死黑：
- **焦墨** `#1D1C1A` / **松烟墨** `#262422`：用于大字书法主标题、近景枯枝、舟楫轮廓。
- **浓墨** `#33302C` / **重墨** `#4A4640`：用于近山皴擦、人物衣褶、案头书卷。
- **淡墨** `#7A766E` / **清墨** `#AEB0AC`：用于远山层峦、水面波纹、副标题与眉题分隔线。

### 3. 设色山水与雅致主题色（`mineral_theme_color`）
单张图最多选 1–2 个矿物/植物传统色作为冷暖调和，保持低饱和度与空气感：
- **青绿/苍翠系**：**竹青** `#789262`、**苍筤** `#739782`、**花青** `#2B4C65`、**石青** `#2E5984`、**螺青** `#3F5056`（适合半山松影、春山、江水）。
- **赭石/秋山系**：**赭石** `#845A33`、**茶褐** `#6E513B`、**秋香** `#D9B611`、**缃色** `#E9C983`（适合秋林、茅亭、孤灯夜读、茶烟）。

### 4. 朱印与视觉点睛色（`vermilion_accent`）
全图高饱和点睛面积控制在 **1%–3%**（如一枚朱文小印、一叶红枫或一盏灯火）：
- **朱砂** `#C83C23` / **印泥红** `#B13525` / **胭脂** `#9D2933` / **泥金** `#C89B40`。

## 二、材质、笔触与字形规范

- **纸张肌理（Paper Texture）**：可见细腻的手工宣纸纤维、水墨渗化毛边（飞白与晕染），无塑料感渐变、无 3D 渲染高光、无数码锐利黑框。
- **字体排印（Calligraphy & Serif Hierarchy）**：
  - 主标题：苍劲舒展的行楷/行书或高对比宋刻衬线体（焦墨 `#1D1C1A`），笔画饱满、结构端庄。
  - 副标题/眉题：清雅宋体/楷体（重墨 `#4A4640`），字距微宽（tracking 0.15em–0.25em）。
- **排版说明隔离**：Prompt 中所有传统色 HEX 与字号参数必须放在括号内，并显式声明「括号内为色彩与排版参数，禁止作为可见文字画入画面」。

## 三、编译字段与验收（Level B 契约）

- `compile_fields`：
  - `paper_base_color`：纸本底色名与 HEX
  - `ink_five_tones`：焦/浓/重/淡/清墨的分配对象
  - `mineral_theme_color`：1–2 个传统矿物/植物配色的名称与作用区域
  - `vermilion_accent`：朱砂/印泥红点睛位置（占比 ≤3%）
  - `calligraphy_and_paper_texture`：宣纸肌理、水墨晕染与书体角色
- `acceptance`：
  - `traditional_palette_harmony`：画面呈宣纸水墨与传统矿物色质感，无霓虹色、塑料高光或刺眼纯白底
  - `ink_hierarchy_clear`：主标题焦墨醒目，远景淡墨退后，图文对比度高
  - `no_parameter_text_leak`：传统色名或 HEX 代码未泄露为画面可见文字
